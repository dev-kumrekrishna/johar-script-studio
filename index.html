About Johar Script Studio

Johar Script Studio is a digital platform created to make Indigenous scripts easier to write, learn and preserve.

The project focuses on script typing, transliteration, learning resources and digital tools for Indigenous language and writing systems.

Johar Script Studio is also part of the wider work of Koya Community — a platform dedicated to preserving and celebrating Adivasi culture, history and knowledge.

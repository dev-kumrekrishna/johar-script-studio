# Johar Script Studio

**Write • Learn • Convert • Preserve**

Johar Script Studio is a web-based platform created to make
Indigenous scripts easier to write, learn and explore digitally.

The project focuses on script typing, learning resources,
transliteration and digital preservation.

---

## 🌿 About

Johar Script Studio is built around the idea that Indigenous
writing systems should also have a place in the modern digital
world.

The platform provides tools and learning resources for
Indigenous scripts and their users.

Johar Script Studio is also connected with the wider work of
**Koya Community**, a platform dedicated to preserving and
celebrating Adivasi culture, history and knowledge.

---

## ✨ Features

- Indigenous script typing
- Custom virtual keyboard
- Real-time typing
- Script-specific fonts
- Transliteration
- Typing guide
- Vowels
- Matras
- Consonants
- Barah Khadi
- Numbers
- Live examples
- Script selection
- Visual font-size controls
- Copy translated/script text
- Responsive mobile design
- Dark interface
- Progressive Web App support
- Offline caching

---

## 📝 Supported Scripts

Currently the project includes support for scripts such as:

- Masaram Gondi
- Gunjala Gondi

Additional scripts can be added in the future.
